# 페이지 우선 Temporary Staging 실검증 결과

검증일: 2026-09-14  
배포 URL: `https://geographical-kyle-screenshot-andy.trycloudflare.com/`  
대상 URL: `https://kakaogames.com/`  
TC: `KG-WEB-001`의 접속, 로딩 대기 및 HTTPS 정상 노출 기대 결과를 단일 자연어 TC로 입력

## 후속 재검증

같은 날 최신 main `3d16ff8`과 migration `0010_resource_domains`를 Temporary Staging에 재배포한 뒤 동일 URL을 다시 분석했다. 결과는 `COMPLETED`, 검증 요소 29개로 복구되어 아래 P0의 요소 0개 현상은 구버전 배포 상태에서 발생한 것으로 확인됐다. title 공란은 남아 있으며 UI는 `제목 없음` fallback을 유지한다. 요소 0개 및 실행 선택 0개일 때의 프론트 사전 차단도 최신 번들에 포함됐다.

## 결과 요약

**실패 — 정상 사용자 시나리오의 승인 및 Worker 실행까지 진행할 수 없다.**

로그인과 AI 시나리오 진입은 정상이다. KakaoGames discovery는 `COMPLETED`로 종료됐지만 페이지 제목은 `제목 없음`, 검증 요소는 `0개`였다. 이후 기본 시나리오 생성은 허용됐고 TC 다섯 항목이 모두 `TC ONLY`로 생성됐다. 페이지 근거 단계는 한 건도 없었다.

모든 비교 항목을 `제외`로 저장해 revision 2에서 7까지 증가하는 것은 확인했다. 미결정이 0건이 되자 승인 버튼이 활성화됐지만, 승인 요청은 `실행할 검증 단계가 없습니다.`로 실패했다. 실행 설정, 실행 계획, Worker 및 증적 화면은 이번 흐름에서 검증할 수 없었다.

## 발견 문제와 우선순위

### P0 — 배포 discovery가 KakaoGames 렌더링 후보를 수집하지 못함

- 2026-09-11 main 문서에는 동일 URL에서 제목, 본문 및 후보 29개 수집으로 기록돼 있으나 현재 Temporary Staging 결과는 제목 없음/0개다.
- 배포 이미지, migration `0010_resource_domains`, resource allowlist 및 Playwright 렌더 안정화 코드가 현재 환경에 실제 적용됐는지 백엔드에서 확인해야 한다.
- `COMPLETED + elements=0`을 성공으로 오인하지 않도록 분석 결과 상태 또는 warning 계약도 필요하다.

### P1 — 프론트가 빈 시나리오의 승인을 사전에 막지 않음

- `pendingCount=0`만으로 승인 버튼이 활성화된다.
- `scenario.steps.length === 0` 또는 실행 선택이 0개이면 승인 버튼을 비활성화하고 `페이지에서 실행 가능한 검증 단계를 찾지 못했습니다. 다시 분석해 주세요.`를 지속 표시해야 한다.
- 현재는 사용자가 모든 검토를 끝낸 뒤 서버 오류로 이유를 알게 된다.

### P1 — 완료 상태가 실제 사용 가능 상태를 표현하지 못함

- 분석 진행은 COMPLETED, 후보 검증 단계도 완료로 보이지만 다음 단계는 실행 불가능하다.
- `요소 0개`, `제목 없음`, 경고 존재 시 `검토 필요/분석 불충분`으로 표시하고 기본 시나리오 생성 버튼을 차단하는 편이 사용자 기대와 맞다.

### P2 — 자연어 TC 분류 품질

- `제목:`과 `전제조건:`이 독립 실행 요구사항으로 분리돼 TC ONLY 검토 행을 증가시킨다.
- 접속 URL과 로딩 대기는 page navigation/wait 근거와 매칭되지 않았다.
- TC 메타데이터, 전제조건, action, expected result의 역할을 유지하는 추출·비교 계약 보완이 필요하다.

## 프론트 후속 완료 조건

1. 요소 0개이면 기본 시나리오 생성과 승인을 사전 차단한다.
2. 분석 완료와 실행 가능한 후보 확보를 별도 상태로 표시한다.
3. 지속 오류/경고에 재분석 행동을 연결한다.
4. 백엔드 수정 배포 후 동일 URL로 페이지 근거 단계가 한 개 이상 생성되는지 재검증한다.
5. 선택 저장 → 승인 → 실행 설정 → 계획 확인 → Worker → PNG 증적까지 전체 흐름을 통과한다.

테스트 계정 자격증명은 저장소, 문서, 브라우저 저장소에 기록하지 않았다.
